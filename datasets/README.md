# Datasets

This directory is gitignored. Place data here locally.

```
datasets/
  fma_small/        FMA small subset: numbered folders (000-155) of .mp3 files
  abstract_art/     abstract artwork images (.png / .jpg)
  byol_features/    generated by approaches/03_byol_a_encoder/extract_byol_features.py
  byol_mel_cache/   generated by approaches/03_byol_a_encoder/train_byol_a.py
```

## Sources

- FMA: https://github.com/mdeff/fma
- Abstract art: the image set used in 2025 is not documented, and its size is reported inconsistently in the 2025 material (1,700 to 7,990 images). A documented, reproducible image set is defined on the `base` branch.
